SHIGAFLOW INSTALLER BUILD

This package contains your existing project plus installer packaging files.
The actual Windows installer EXE must be built on Windows because the app is WPF and uses the Windows .NET target.

Requirements on the build PC:
- Windows 10/11 x64
- .NET 8 SDK (or Visual Studio with .NET desktop development support)
- Inno Setup 6: https://jrsoftware.org/isinfo.php

Build:
1. Extract this ZIP to a normal folder (not inside another ZIP).
2. Open PowerShell in the extracted folder.
3. Run: powershell -ExecutionPolicy Bypass -File .\Build-Shigaflow-Installer.ps1
4. The installer should be created at .\installer\Shigaflow-Setup.exe

The script publishes both the WPF app and native host as self-contained single-file x64 executables, then compiles the Inno Setup installer. The installer places the app and extension under %LOCALAPPDATA%\Shigaflow so the existing native-host code's expected paths remain consistent.

After installation, the user loads the installed BrowserExtension folder via chrome://extensions > Developer mode > Load unpacked, then launches "Connect Shigaflow to Chrome" from the Start menu and enters the extension ID. Chrome must be fully restarted afterward.

Please test on a clean Windows user account / spare PC before sharing broadly. Unsigned executables and unpacked extensions may trigger security warnings.
