Shigaflow – Torrents Table QOL Update (v13)

Changes
- Replaced the Torrents list's fixed-width header/row layout with a WPF DataGrid.
- Torrent columns can be resized by dragging their header separators.
- Column order is fixed; users cannot reorder columns.
- Column widths are saved in the existing settings.json and restored at next launch.
- Removed the Actions column and its per-row Pause/Resume button. Existing right-click context menu actions remain.
- Added an Added column showing the original added date only (dd MMM yyyy).
- Clicking any column header sorts by that column. First click is ascending; clicking it again reverses to descending. Clicking another column starts ascending.
- Sorting uses numeric values for size and transfer speeds, and the actual DateTime for Added.
- Long torrent names show an ellipsis and reveal the full name in a tooltip.
- Existing torrent AddedAt values are preserved. Legacy records with no AddedAt value receive the current date as a fallback.
- Retains the v12 torrent metadata-name fix and the existing regular download/browser integration source.

Validation
- MainWindow.xaml parsed as XML successfully.
- ZIP integrity checked after packaging.
- A Windows/.NET build and runtime test were not possible in this environment; build and test in Visual Studio before replacing your working build.
