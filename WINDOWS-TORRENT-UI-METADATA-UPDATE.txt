Shigaflow Windows - Torrent UI and metadata-name update

Changes:
- Torrent list now has one inline Pause/Resume button, matching Your Downloads.
- Stop, Open Download Folder, and Remove Torrent remain available in the torrent right-click menu.
- Both right-click menus now show matching Segoe MDL2 action icons.
- Menu dividers use full-width themed borders instead of the narrow WPF Separator rendering.
- Magnet display-name resolution now checks metadata-bearing handle/status objects reflectively and, when the alpha binding does not expose the metadata name, checks for newly-created torrent storage entries in the selected download folder. This fallback is based on entries created after the magnet was added, so unrelated pre-existing files are ignored.
- Existing libtorrent engine, torrent controls, history, and download UI are retained.

Validation:
- MainWindow.xaml and App.xaml parsed successfully as XML.
- ZIP integrity checked after packaging.
- A Windows .NET build/runtime test was not available in this environment.
