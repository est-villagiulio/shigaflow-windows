Shigaflow Google Drive bulk ZIP fix — V10
Date: 2026-11-12

Changes
1. Browser extension selected-item detection now checks aria-selected, data-selected, aria-checked and checked checkbox states, then deduplicates Drive file IDs.
2. Native host normalizes explicitly marked Google Drive bulk requests to a .zip filename before allow-list validation and forwarding to the WPF app.
3. Browser extension version is now 1.3.0.
4. Existing single-file Google Drive direct authenticated capture path is preserved.

Verification performed in this environment
- ZIP source archive integrity checked.
- JavaScript syntax checked with Node.js.
- JSON manifest parsed.
- Native host source changes reviewed.

Not performed
- Windows .NET publish/build, Inno Setup compilation, or runtime test against a signed-in Google Drive account. Those require a Windows environment and are not claimed as completed.


V11 torrent identity fix

- Prevented the magnet display-name fallback from scanning a shared save folder
  when another torrent uses the same destination.

  torrent cannot rename an existing completed torrent and redirect its Open File
