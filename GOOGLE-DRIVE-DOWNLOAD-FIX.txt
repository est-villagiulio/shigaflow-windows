Google Drive download fix

- The previous downloader could treat Google's small HTML confirmation page as the downloaded file.
  This produced a 2-3 KB file, marked the task Complete, and showed only one segment.
- Google Drive range probing now follows its hidden GET confirmation form while preserving byte-range
  headers, so a successful probe can discover the actual file length and restore Resume: Yes.
- Segmented requests use the same confirmation resolver, allowing the configured connection count
  (for example, 8) to create the expected number of parts when Google returns valid byte ranges.
- Google user-content cookie scope is now included in the browser handoff and remains restricted to
  Google-owned domains. Cookies are still passed only in the short-lived local handoff.
- HTML interstitial pages are rejected instead of being saved and marked complete. A real HTML file
  with an attachment filename remains downloadable.

Build verification: ZIP structure and JavaScript syntax checked. A Windows .NET build was not run
because the current environment does not have the .NET SDK installed.
