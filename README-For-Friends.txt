SHIGAFLOW — INSTALL NOTES

1. Install Shigaflow using Shigaflow-Setup.exe.
2. Open Chrome and go to chrome://extensions.
3. Turn on Developer mode.
4. Click Load unpacked and select this folder:
   %LOCALAPPDATA%\Shigaflow\BrowserExtension
5. Copy the Extension ID shown on the Shigaflow extension card.
6. From the Windows Start menu, open "Connect Shigaflow to Chrome" and paste the ID when asked.
7. Completely exit Chrome (including background processes), then reopen it.
8. Open Shigaflow and test with a direct HTTP/HTTPS download link.

IMPORTANT
- Chrome may show warnings because this is a manually loaded extension.
- Keep the BrowserExtension folder where the installer placed it; do not move or rename it.
- Browser capture may not work for links that require a website login, cookies, or special headers.
- If Chrome's extension ID changes (for example, after loading a different copy), run "Connect Shigaflow to Chrome" again and enter the new ID.
